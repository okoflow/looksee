## Версионирование

LookSee следует [семантическому версионированию](https://semver.org/lang/ru/), и номер
один на всю систему — api, сервис инференса, studio и этот сайт документации выходят
вместе.

Проект пока на линии `0.x`: публичного релиза ещё не было, поэтому минорная версия
может изменить поведение, на которое оператор полагается. `1.0.0` выйдет вместе с
первым публичным релизом. Дальше:

- **Мажорная** — обновление требует ручной работы: миграция без отката,
  переименованная или удалённая переменная окружения, схема workflow, которой
  перестают удовлетворять существующие графы, исчезнувший маршрут. Что именно нужно
  сделать, такой релиз перечисляет в разделе **Breaking**.
- **Минорная** — новые возможности, типы узлов, архитектуры моделей и документация.
- **Патч** — исправления и обновления зависимостей.

Рефакторинг, которого оператор не видит, ничего не меняет в совместимости, поэтому
мажорную версию не занимает.
