## Требования

Python 3.12 с [uv](https://docs.astral.sh/uv/), Node.js 24 с pnpm 11 и Docker
с Compose 2.24 или новее.

## Запуск из исходников

Выполняйте все команды из корня репозитория:

```bash
uv sync --all-packages --extra cpu
pnpm -C apps/studio install --frozen-lockfile

docker compose up -d postgres redis mediamtx
uv run --package looksee-api alembic -c apps/api/alembic.ini upgrade head

uv run --package looksee-api fastapi dev apps/api/src/api/main.py
uv run --package looksee-inference faststream run inference.main:app
pnpm -C apps/studio dev
```

Раскомментируйте секцию `Native development outside compose` в `.env`, чтобы процессы
на хосте ходили в сервисы по localhost. Корневой `.env` — единственный источник
конфигурации; `.env.example` — канонический список настроек.

## Проверки

Запускайте перед завершением любого изменения:

```bash
uv run ruff check .
uv run ruff format --check .
pnpm -C apps/studio lint
pnpm -C apps/studio typecheck
pnpm -C apps/studio build
docker compose --env-file .env.example config --quiet
```

После изменения ORM-моделей дополнительно держите цепочку миграций чистой:

```bash
uv run --package looksee-api alembic -c apps/api/alembic.ini check
```

## Структура репозитория

| Путь | Ответственность |
| --- | --- |
| `apps/api` | FastAPI control plane: исполнение воркфлоу, алерты, realtime-обновления |
| `apps/inference` | ONNX-детекция, трекинг объектов, жизненный цикл воркеров камер |
| `apps/studio` | Next.js-редактор воркфлоу и интерфейс живого мониторинга |
| `apps/docs` | Сайт документации на Fumadocs |
| `packages/shared` | Строгие контракты API ↔ inference и схема манифеста модели |
| `packages/brand` | Канонические бренд-ассеты LookSee |
| `ee/` | Код коммерческой редакции, лицензия `ee/LICENSE` |
| `docker/` | Конфигурация MediaMTX |
| `models/` | Игнорируемые read-only бандлы моделей, монтируются в рантайме |
