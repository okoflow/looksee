LookSee는 라이브 스트림, 브라우저 웹캠, 로컬 비디오 파일을 위한 셀프 호스팅
비디오 분석 시스템입니다. ONNX 객체 감지를 실행하고, 객체를 추적하며, 시맨틱
이벤트를 도출하고, 이러한 이벤트를 시각적 워크플로를 통해 알림과 외부 통합으로
라우팅합니다.

## 어디서부터 시작할까요

- [아키텍처](./architecture.mdx)는 서비스 경계, 데이터 흐름, 의도한 상태,
  일관성 보장을 설명합니다.
- [워크플로 레퍼런스](./workflow-reference.mdx)는 카메라 소스, 노드 동작,
  유효성 검사, 액션을 정의합니다.
- [모델 카탈로그](./model-catalog.mdx)는 번들 매니페스트, 이벤트 매핑,
  지원되는 ONNX 시그니처를 정의합니다.
- [로컬에서 워크플로 테스트하기](./manual-testing.mdx)는 로컬 비디오 파일로
  엔드 투 엔드 스모크 테스트를 실행합니다.

LookSee 자체를 실행하려면
[리포지토리 README](https://github.com/okoflow/looksee#run-with-docker)의
안내를 따르십시오.
