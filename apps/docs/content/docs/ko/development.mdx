## 사전 요구 사항

Python 3.12와 [uv](https://docs.astral.sh/uv/), Node.js 24와 pnpm 11, 그리고
Compose 2.24 이상이 포함된 Docker가 필요합니다.

## 소스에서 실행

모든 명령은 저장소 루트에서 실행합니다:

```bash
uv sync --all-packages --extra cpu
pnpm -C apps/studio install --frozen-lockfile

docker compose up -d postgres redis mediamtx
uv run --package looksee-api alembic -c apps/api/alembic.ini upgrade head

uv run --package looksee-api fastapi dev apps/api/src/api/main.py
uv run --package looksee-inference faststream run inference.main:app
pnpm -C apps/studio dev
```

호스트 프로세스가 localhost 서비스 URL을 사용하도록 `.env`에서
`Native development outside compose` 섹션의 주석을 해제합니다. 루트 `.env`는
유일한 설정 소스이며, `.env.example`은 설정 항목의 정식 목록입니다.

## 검사

변경을 마치기 전에 실행합니다:

```bash
uv run ruff check .
uv run ruff format --check .
pnpm -C apps/studio lint
pnpm -C apps/studio typecheck
pnpm -C apps/studio build
docker compose --env-file .env.example config --quiet
```

ORM을 변경한 후에는 마이그레이션 체인도 깨끗하게 유지합니다:

```bash
uv run --package looksee-api alembic -c apps/api/alembic.ini check
```

## 저장소 구조

| 경로 | 역할 |
| --- | --- |
| `apps/api` | FastAPI 컨트롤 플레인, 워크플로 실행, 알림, 실시간 업데이트 |
| `apps/inference` | ONNX 탐지, 객체 추적, 카메라 워커 수명 주기 |
| `apps/studio` | Next.js 워크플로 편집기와 라이브 모니터링 인터페이스 |
| `apps/docs` | Fumadocs 문서 사이트 |
| `packages/shared` | API와 inference 간의 엄격한 계약과 모델 매니페스트 스키마 |
| `packages/brand` | 정식 LookSee 브랜드 자산 |
| `ee/` | `ee/LICENSE` 라이선스를 따르는 상용 에디션 코드 |
| `docker/` | MediaMTX 설정 |
| `models/` | Git에서 무시되며 런타임에 마운트되는 읽기 전용 모델 번들 |
