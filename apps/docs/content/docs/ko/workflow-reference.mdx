워크플로는 카메라 소스, 감지, 필터, 액션으로 이루어진 방향 그래프입니다. 초안은
PostgreSQL에 저장되며, API는 워크플로가 활성화되기 전에 런타임 요구 사항을
검증합니다.

## 그래프 규칙

저장되는 모든 그래프는 고유한 노드 및 엣지 ID와 유효한 엣지 끝점을 가져야 하며,
분기 메타데이터는 필터에서 나가는 엣지에만 있어야 합니다. 초안에는 불완전하거나
연결되지 않은 노드가 포함될 수 있습니다.

활성화된 모든 소스 경로는 다음 규칙을 충족해야 합니다:

- 도달 가능한 그래프에 순환이 없습니다.
- 소스가 정확히 하나의 Detect 노드에 도달합니다.
- 선택한 모델이 존재하고, 구성된 이벤트와 클래스를 지원합니다.
- 도달 가능한 모든 노드에 필수 런타임 값이 있습니다.

각 필터는 일치하는 이벤트를 `if` 엣지로, 일치하지 않는 이벤트를 `else` 엣지로
라우팅합니다. 레이블이 없는 필터의 나가는 엣지는 `if`로 동작합니다.

## 카메라 소스

MediaMTX는 추론과 브라우저 재생을 위해 모든 소스를 UUID 이름의 단일 경로로
정규화합니다.

| 소스 | 구성 |
| --- | --- |
| RTSP | `rtsp://` 또는 `rtsps://` 업스트림 URL |
| RTMP | `rtmp://` 또는 `rtmps://` 업스트림 URL |
| SRT | `srt://` 업스트림 URL |
| WHEP | 원격 `http://`, `https://`, `whep://` 또는 `wheps://` 엔드포인트 |
| WebRTC | URL 없음. 워크플로를 실행한 뒤 WHIP을 통해 브라우저 웹캠을 게시합니다 |
| File | `MEDIA_DIR` 내부의 상대 경로. MediaMTX가 FFmpeg을 통해 반복 재생합니다 |

파일 경로에는 영문자, 숫자, `.`, `_`, `-`, `/`를 사용할 수 있습니다. 공백, 숨김
경로 세그먼트, `..`, 셸 문자는 사용할 수 없습니다.

## 감지

Detect 노드는 다음을 선택합니다:

- 런타임 카탈로그의 모델.
- 통과시킬 이벤트 종류. 비워 두면 모델이 노출하는 모든 이벤트가 통과됩니다.
- 0에서 1 사이의 신뢰도 임계값.
- 초당 1회에서 15회 사이로 검사하는 추론 빈도.

현재 하나의 카메라 소스는 도달 가능한 Detect 노드 하나만 지원합니다. 번들 및
이벤트 규칙은 [모델 카탈로그](./model-catalog.mdx)를 참조하십시오.

## 필터

| 노드 | 일치 조건 |
| --- | --- |
| If / Else | 이벤트 종류, 객체 클래스, 감지 수 또는 최대 신뢰도가 타입이 지정된 비교를 충족합니다 |
| Zone | 하나 이상의 감지 중심점이 다각형 내부에 있습니다 |
| Class | 하나 이상의 감지 레이블이 선택한 클래스에 속합니다 |
| Debounce | 노드가 쿨다운 동안 이벤트를 통과시킨 적이 없습니다 |
| Schedule | 이벤트 시간이 선택한 시간대와 요일 안에 있거나, 반전한 경우 그 밖에 있습니다 |
| Line crossing | 추적된 객체가 두 점으로 이루어진 선을 선택한 방향으로 가로지릅니다 |
| Dwell | 추적된 객체가 구성된 시간 동안 다각형 내부에 머무릅니다 |
| Count | 선택적 다각형 내의 감지 수가 임계값 이상 또는 이하입니다 |
| Size | 하나 이상의 경계 상자 면적이 구성된 프레임 대비 비율 범위 안에 있습니다 |

Zone 및 Dwell 노드는 워크플로를 실행하기 전에 다각형이 필요합니다. Line
crossing에는 두 개의 점이 필요합니다. Count의 다각형이 비어 있으면 전체 프레임을
의미합니다.

Schedule 평가에는 `EVENT_TIMEZONE`이 사용됩니다. Debounce, line-crossing, dwell 및
전역 이벤트 쿨다운 상태는 API 프로세스 안에 있으며, 프로세스가 재시작되거나 새
실행이 시작되면 초기화됩니다.

## 액션

| 노드 | 동작 | 필요 항목 |
| --- | --- | --- |
| Alert | `info`, `warning` 또는 `critical` 알림을 저장합니다 | 없음 |
| Snapshot | 최신 JPEG를 저장하고(선택적으로 상자 포함) 다운스트림 컨텍스트에 추가합니다 | 없음 |
| Telegram | 텍스트 또는 스냅샷 사진을 전송합니다 | Telegram 봇 자격 증명 |
| Webhook | `GET`, `POST` 또는 `PUT`으로 이벤트 페이로드를 전송합니다 | 없음 |
| Email | 템플릿 기반 메시지와 선택적 JPEG 첨부 파일을 전송합니다 | SMTP 자격 증명 |
| MQTT | 템플릿 또는 기본 JSON 페이로드를 게시합니다 | MQTT 자격 증명 |
| Discord | 웹훅을 통해 이벤트를 채널로 전송합니다 | Discord 웹훅 자격 증명 |

통합 시크릿은 자격 증명 페이지에 보관되며 저장 시 암호화됩니다. 노드는 id로 자격
증명을 참조하며, 워크플로를 활성화할 때 해당 참조가 올바르게 해석되는지 검증합니다.

`snapshot_url` 또는 첨부 파일이 필요한 알림 액션 앞에 Snapshot을 배치하십시오.
템플릿은 `{kind}`, `{camera_id}`, `{ts}`, `{count}`, `{snapshot_url}`을 지원합니다.
유효하지 않은 자리 표시자는 로그에 기록되며, 원본 템플릿이 변경되지 않은 채 그대로
전달됩니다.

액션 실패는 로그에 기록되며, 이후 노드의 실행을 막지 않습니다.

## 프리셋

생성 대화 상자는 빈 워크플로와 현재 8개의 프리셋을 제공합니다:

- 업무 시간 외 침입
- 인원 계수
- 배회
- 주차 점유
- 대기열 모니터
- 헬멧 착용 준수
- 화재 및 연기
- 빈 주차 공간

프리셋은 바로 실행할 수 있는 배포가 아니라 편집 가능한 초안을 생성합니다. 모든
프리셋은 모델을 선택하지 않은 상태로 둡니다. 실행하기 전에 카메라, 모델, 필요한
구역이나 선, 외부 액션 대상을 구성하십시오.

헬멧, 화재 및 연기, 빈 주차 공간 프리셋은 시맨틱 이벤트 종류를 미리 채웁니다.
선택한 모델이 해당 종류를 노출해야 합니다. 다른 프리셋은 설치된 모델에서 이벤트를
선택할 수 있도록 이벤트 선택을 비워 둡니다.
