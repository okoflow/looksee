תהליך עבודה הוא גרף מכוון של מקורות מצלמה, זיהוי, מסננים ופעולות. טיוטות נשמרות
ב־PostgreSQL, וה־API מאמת את דרישות זמן הריצה לפני שתהליך עבודה מופעל.

## כללי הגרף

לכל הגרפים השמורים חייבים להיות מזהים ייחודיים לצמתים ולקשתות, נקודות קצה תקינות
לקשתות, ומטא־נתוני ענף רק על קשתות היוצאות ממסננים. טיוטה יכולה להכיל צמתים לא
שלמים או מנותקים.

כל נתיב מקור שמופעל חייב לעמוד בכללים האלה:

- הגרף הנגיש חסר מעגלים.
- המקור מגיע לצומת "Detect" אחד בדיוק.
- המודל שנבחר קיים ותומך באירועים ובמחלקות שהוגדרו.
- לכל צומת נגיש מוגדרים כל ערכי זמן הריצה הנדרשים.

כל מסנן מנתב התאמה לקשתות `if` ואי־התאמה לקשתות `else`. קשת יוצאת של מסנן ללא
תווית מתנהגת כמו `if`.

## מקורות מצלמה

MediaMTX מנרמל כל מקור לנתיב יחיד ששמו UUID, לצורכי היסק (inference) ולניגון
בדפדפן.

| מקור | תצורה |
| --- | --- |
| RTSP | כתובת URL של זרם מקור `rtsp://` או `rtsps://` |
| RTMP | כתובת URL של זרם מקור `rtmp://` או `rtmps://` |
| SRT | כתובת URL של זרם מקור `srt://` |
| WHEP | נקודת קצה מרוחקת `http://`, `https://`, `whep://` או `wheps://` |
| WebRTC | ללא URL; הריצו את תהליך העבודה ואז פרסמו את מצלמת הרשת של הדפדפן דרך WHIP |
| File | נתיב יחסי בתוך `MEDIA_DIR`; MediaMTX מנגן אותו בלולאה באמצעות FFmpeg |

נתיבי קבצים יכולים להכיל אותיות, ספרות, `.`, `_`, `-` וכן `/`. הם אינם יכולים
להכיל רווחים, מקטעי נתיב נסתרים, `..` או תווי מעטפת (shell).

## זיהוי

בצומת "Detect" נבחרים:

- מודל מקטלוג זמן הריצה.
- סוגי אירועים להעברה; בחירה ריקה מעבירה כל אירוע שהמודל חושף.
- סף ביטחון בין 0 ל־1.
- קצב היסק בין 1 ל־15 בדיקות בשנייה.

מקור מצלמה אחד תומך כיום בצומת "Detect" נגיש אחד. לכללי החבילות (bundles)
והאירועים, ראו את [קטלוג המודלים](./model-catalog.mdx).

## מסננים

| צומת | תנאי התאמה |
| --- | --- |
| If / Else | סוג אירוע, מחלקת אובייקט, מספר זיהויים או ביטחון מרבי עומדים בהשוואה מבוססת־טיפוס |
| Zone | מרכז של זיהוי אחד לפחות נמצא בתוך הפוליגון |
| Class | תווית של זיהוי אחד לפחות שייכת למחלקות שנבחרו |
| Debounce | הצומת לא העביר אירוע במהלך זמן הצינון (cooldown) שלו |
| Schedule | זמן האירוע נופל בתוך השעות וימי השבוע שנבחרו, או מחוץ להם כאשר מופעל היפוך |
| Line crossing | אובייקט במעקב חוצה קו בן שתי נקודות בכיוון שנבחר |
| Dwell | אובייקט במעקב נשאר בתוך פוליגון למשך הזמן שהוגדר |
| Count | מספר הזיהויים בפוליגון אופציונלי גדול או שווה לסף, או קטן או שווה לו |
| Size | שטח של תיבה תוחמת אחת לפחות נופל בתוך הטווח שהוגדר כחלק יחסי מהפריים |

הצמתים "Zone" ו־"Dwell" דורשים פוליגונים לפני שתהליך העבודה יכול לרוץ.
"Line crossing" דורש שתי נקודות. פוליגון "Count" ריק משמעו הפריים כולו.

הערכת "Schedule" משתמשת ב־`EVENT_TIMEZONE`. מצב הצמתים "Debounce",
"Line crossing" ו־"Dwell" ומצב זמן הצינון הגלובלי של אירועים נשמרים בתהליך
ה־API ומתאפסים כשהוא מופעל מחדש או כשמתחילה ריצה חדשה.

## פעולות

| צומת | התנהגות | דורש |
| --- | --- | --- |
| Alert | שומר התראה ברמת `info`, `warning` או `critical` | ללא |
| Snapshot | שומר את ה־JPEG העדכני ביותר, אופציונלית עם תיבות תוחמות, ומוסיף אותו להקשר במורד הזרם | ללא |
| Telegram | שולח טקסט או את תמונת המצב כתמונה | פרטי גישה של בוט Telegram |
| Webhook | שולח את מטען האירוע (payload) באמצעות `GET`, `POST` או `PUT` | ללא |
| Email | שולח הודעה מבוססת תבנית, ולפי בחירה קובץ JPEG מצורף | פרטי גישה של SMTP |
| MQTT | מפרסם תבנית או את מטען ה־JSON המוגדר כברירת מחדל | פרטי גישה של MQTT |
| Discord | שולח את האירוע לערוץ באמצעות webhook | פרטי גישה ל־webhook של Discord |

סודות האינטגרציות נשמרים בעמוד פרטי הגישה, מוצפנים בעת אחסון; צומת מפנה לפרטי
גישה לפי id, והפעלת תהליך העבודה מוודאת שההפניה מצביעה על פרטי גישה קיימים.

מקמו את "Snapshot" לפני פעולות שליחת הודעות הזקוקות ל־`snapshot_url` או לקובץ
מצורף. תבניות תומכות ב־`{kind}`, `{camera_id}`, `{ts}`, `{count}`
ו־`{snapshot_url}`. ממלאי מקום (placeholders) לא תקינים נרשמים ביומן, והתבנית
המקורית נמסרת ללא שינוי.

כשל בפעולה נרשם ביומן ואינו מונע מהצמתים הבאים לרוץ.

## פריסטים

דיאלוג היצירה מציע תהליך עבודה ריק ושמונה פריסטים הזמינים כיום:

- חדירה מחוץ לשעות הפעילות
- ספירת אנשים
- שוטטות
- תפוסת חניה
- ניטור תור
- בקרת חבישת קסדות
- אש ועשן
- מקומות חניה פנויים

הפריסטים יוצרים טיוטות שניתן לערוך, ולא פריסות (deployments) מוכנות להרצה. כל
פריסט משאיר את המודל לא נבחר. לפני ההרצה הגדירו את המצלמה, המודל, האזורים או
הקווים הנדרשים, וכל יעדי הפעולות החיצוניות.

הפריסטים "בקרת חבישת קסדות", "אש ועשן" ו"מקומות חניה פנויים" ממלאים מראש סוגי
אירועים סמנטיים. המודל שנבחר חייב לחשוף סוגים אלה. שאר הפריסטים משאירים את
בחירת האירועים ריקה, כך שתוכלו לבחור אירועים מתוך המודל המותקן.
