---
title: תיעוד
description: התיעוד של LookSee בדרך.
---

ברוכים הבאים ל-LookSee — מערכת self-hosted לאנליטיקת וידאו עבור זרמים חיים, מצלמות רשת
בדפדפן וקובצי וידאו מקומיים.

התיעוד עדיין נכתב ויופיע כאן בקרוב.

בינתיים הכול נמצא ב-[GitHub](https://github.com/okoflow/looksee): קוד המקור, מעקב
התקלות והערות הגרסאות. אם תרצו לעזור, פתחו issue או שלחו pull request.
