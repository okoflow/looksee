Welcome to LookSee — a self-hosted video analytics system for live streams, browser
webcams, and local video files.

The documentation is still being written and will appear here soon.

Until then everything lives on [GitHub](https://github.com/okoflow/looksee): the source,
the issue tracker, and the release notes. If you would like to help, open an issue or
send a pull request.
