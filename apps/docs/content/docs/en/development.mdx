## Prerequisites

Python 3.12 with [uv](https://docs.astral.sh/uv/), Node.js 24 with pnpm 11, and Docker
with Compose 2.24 or later.

## Run from source

Run all commands from the repository root:

```bash
uv sync --all-packages --extra cpu
pnpm -C apps/studio install --frozen-lockfile

docker compose up -d postgres redis mediamtx
uv run --package looksee-api alembic -c apps/api/alembic.ini upgrade head

uv run --package looksee-api fastapi dev apps/api/src/api/main.py
uv run --package looksee-inference faststream run inference.main:app
pnpm -C apps/studio dev
```

Uncomment the `Native development outside compose` section of `.env` so host processes
use localhost service URLs. The root `.env` is the only configuration source;
`.env.example` is the canonical list of settings.

## Checks

Run before finishing any change:

```bash
uv run ruff check .
uv run ruff format --check .
pnpm -C apps/studio lint
pnpm -C apps/studio typecheck
pnpm -C apps/studio build
docker compose --env-file .env.example config --quiet
```

After ORM changes, also keep the migration chain clean:

```bash
uv run --package looksee-api alembic -c apps/api/alembic.ini check
```

## Repository layout

| Path | Responsibility |
| --- | --- |
| `apps/api` | FastAPI control plane, workflow execution, alerts, and realtime updates |
| `apps/inference` | ONNX detection, object tracking, and camera worker lifecycle |
| `apps/studio` | Next.js workflow editor and live monitoring interface |
| `apps/docs` | Fumadocs documentation site |
| `packages/shared` | Strict API-to-inference contracts and model manifest schema |
| `packages/brand` | Canonical LookSee brand assets |
| `ee/` | Commercial edition code, licensed under `ee/LICENSE` |
| `docker/` | MediaMTX configuration |
| `models/` | Ignored, read-only model bundles mounted at runtime |
